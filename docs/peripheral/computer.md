# Computer Peripheral Documentation

Interact with an adjacent computer. Type is `computer` for computers, `turtle` for turtles.

## Methods

### turnOn()
Activates the adjacent computer.

### shutdown()
Powers down the adjacent computer.

### reboot()
Restarts the adjacent computer (or turns it on if off).

### getID() → number
Returns the adjacent computer's ID.

### isOn() → boolean
Whether the adjacent computer is powered on.

### getLabel() → string | nil
Returns the adjacent computer's label, or nil if unset.
