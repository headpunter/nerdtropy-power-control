# Keys API Documentation

## Overview

The `keys` module provides constants for all keyboard key codes as generated by the `key` event.

> Key code values are not guaranteed to remain the same between versions. Always use the named constants rather than raw numbers.

## Functions

### getName(code) → string | nil
Converts a numerical key code to its human-readable name.

**Parameters:** `code` (number) — The key code
**Returns:** Name string matching a constant in the keys API, or `nil` if invalid

**Example:**
```lua
keys.getName(keys.enter)
```

## Key Constants

All standard keyboard keys are available as constants, e.g.:
`keys.enter`, `keys.space`, `keys.backspace`, `keys.up`, `keys.down`, `keys.left`, `keys.right`,
`keys.a` through `keys.z`, `keys.zero` through `keys.nine`, `keys.f1` through `keys.f12`,
`keys.leftCtrl`, `keys.rightCtrl`, `keys.leftShift`, `keys.rightShift`, `keys.leftAlt`, `keys.rightAlt`,
`keys.tab`, `keys.capsLock`, `keys.numPad0` through `keys.numPad9`, etc.
